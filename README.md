# TV Minis

Twelve tiny interactive 3D dioramas inspired by famous TV shows. Each scene is a single self-contained `index.html` (Three.js via CDN, all geometry procedural - no copyrighted assets).

Open-source tribute fan art: original low-poly geometry, no show logos, characters, fonts or audio.
